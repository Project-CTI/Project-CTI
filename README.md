# Project-CTI
The Critical Thinking Initiative (CTI) Project website. Live visualizations, community get together and science promotion. Hoping to help prevent the devaluation of critical thought.

## Dash Math! 
A fun dive into math using visualizations, unique animations, dashboards and real-world data. 
Highlighting the importance (and sheer fun!) in finding trends in data sets: unique, simple, complex or 
standard. 

## Community Math Fun! 
Section where volunteers (or any proud person) can upload their math-related work and have 
it publically displayed. Due to risk of so many different things, this will be monitored via strict pull, 
re-merge requests on a daily basis (if not hourly, lol)
